# Quiz Badges Directory

This directory contains badge images that students can download after completing booth quizzes with 80% or higher score.

## Badge Requirements

- **Format:** PNG with transparent background
- **Size:** Recommended 800x800px (square format)
- **Design:** Should include sponsor logo and "Career Launch" branding

## Required Badge Files

Place 4 badge image files in this directory for random selection:

- `badge-1.png`
- `badge-2.png`
- `badge-3.png`
- `badge-4.png`

Each time a student completes a quiz with 80%+, one of these 4 badges will be randomly selected for download.

## Download Behavior

Badges are only downloadable when:
- Quiz is completed
- Score is **80% or higher**
- Badge image files exist in this directory

## Badge Text Displayed

When badge is earned, students see:
> "Good job. Now add this session completion badge to your portfolio in myBlueprint with your session takeaways/reflection."
